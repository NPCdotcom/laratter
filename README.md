# Laratter（コメント機能追加版）

受講番号：6th-32
氏名：德島 颯

## 1. プロダクトの紹介

講義で作成した SNS アプリケーション「Laratter」に，**i18n対応、画像投稿、動画投稿、フォロー機能、通知機能** を追加しました．

- Tweet作成時に画像（4枚まで35MB以下）と動画（一本まで512MB以下）を投稿できる。
- 他のユーザーのプロフィールからフォローを送れる。
- ユーザーは通知からフォローを承認 or 設定による自動承認でフォローを許可できる。
- 多言語対応とそれに合わせた適切なインターフェースを導入。

## 2. こだわった点・苦労した点

- 添付された画像と動画の位置がずれたり、Tweet自体の形式が崩れたりするバグを解消した
- 動画はストリーム形式で読み込むようにした
- いくつかの文字列インターフェースは言語ごとの専用のキーに内容を分離して多言語対応をした
- 多言語対応のためにひたすらにDeeplを回して翻訳した
- 多言語対応について、ユーザーに紐づいた設定がなくとも左下の選択ボックスから選ぶことで他の言語に切り替えられるようにした

## 3. 操作方法

1. トップページから「ログイン」または「新規登録」を行う
2. 「Tweet 作成」から任意の文を入力し、画像や動画を選択する
3. プレビューも忠実に設計したのでそれを確認して投稿する
4. 「Tweet 一覧」から画像や動画のあるTweetを確認、必要ならそれをクリックして拡大できる
5. 言語設定はタブ左下の選択ボックスまたは設定で行える
6. 設定の社交設定から自動でフォローを承認するかどうかを設定できる
7. フォローは「Tweet 一覧」などから投稿者のマイページに飛び、ユーザー名の下にあるボタンでフォロー申請を送れる
